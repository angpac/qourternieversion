## Commands and env

- Commands: `npm run dev`, `npm run build`, `npm run start`, `npm run lint` (no test script).
- Requires `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` env vars at build/run time;
  there's no `.env.example` checked in, so ask the user for these if they're not already set locally.
